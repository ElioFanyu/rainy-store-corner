# 生成提示词 · Prompt

本项目**完全由下面这段提示词驱动生成**，没有使用任何外部模型、贴图或美术资源。
从第一版场景到后续的桌面启动器，都是在这段原始需求上迭代完成的。

---

## 原始提示词

> 请制作一个雨夜便利店街角小场景，以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何UI界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质表现干净，轮廓明确，色彩柔和但富有夜景霓虹的层次感。
>
> 场景主体是一处日式便利店街角，便利店位于底座的视觉中心，外部有典型的日式街角元素：便利店招牌、玻璃橱窗、自动门、屋檐雨棚、门口地垫、自动贩卖机、自行车、雨伞架、垃圾桶、路灯、电线杆、电线、路牌、街角护栏、停车位、排水沟、积水路面、反光斑马线、小巷入口、空调外机、小型公告栏或海报栏等。街道不需要太大，但要有明确的街角转折感，像日本动画里常见的夜晚社区一角。整体模型制作完毕后，增加建筑入场动画，从地面开始慢慢组装模型元素等往上叠加，由散件组成完整场景的效果。不要人物，但便利店内部一定要有足够内容，并且可以透过大面积玻璃窗清楚看到店内。店内可见典型便利店陈设，要让便利店内部显得明亮、温暖、真实、充实

## 关于「根据提示词生成」的说明

- 场景中**没有任何外部模型文件**（无 `.glb` / `.obj` / `.fbx`），所有几何体都由代码用 `BoxGeometry` / `CylinderGeometry` / `SphereGeometry` / `TorusGeometry` / `TubeGeometry` / `ConeGeometry` / `CircleGeometry` / `PlaneGeometry` 拼装。
- 场景中**没有任何外部贴图文件**，招牌、海报、地垫、商品包装、路牌文字全部在运行时用 Canvas 2D 绘制。
- 唯一的第三方代码是 Three.js 本体与其官方示例中的 `OrbitControls` 与后期处理 Pass，已本地化到 `vendor/`。
- 因此整份画面 100% 由上面那段文字描述驱动，可以逐条对照上表验证。
